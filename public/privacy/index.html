Privacy

Personal Vocab Loop keeps your language practice private. Phrases, context tags, and voice recordings stay in private storage in this browser. They are not sent to our servers.

The demo uses separate browser storage. Leaving the demo clears its sample data and never reads your real library. Its technical database name starts with demo:.

Exports are created on your device. An encrypted export uses a passphrase you choose. We do not receive or retain that passphrase. Deleting browser site data can remove your local library, so export a backup if it matters to you.

The app uses no ads, analytics, trackers, accounts, or code from other sites.

If you restore an existing Plus license, its token is stored in this browser. It is sent only to the Sociobot billing API for verification. A valid license adds the option to shuffle due phrases.

Questions: privacy@sociobot.in.
